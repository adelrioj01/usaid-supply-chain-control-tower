# Data and third-party content notice

The project uses USAID Supply Chain Shipment Pricing Data, also identified as the SCMS Delivery History Dataset. USAID published the original dataset under portal identifier `a3rc-nmf6`.

The former `data.usaid.gov` download endpoint is no longer reliable. This repository uses a versioned public mirror:

- Original publisher: U.S. Agency for International Development
- Data.gov catalog: https://catalog.data.gov/dataset/supply-chain-shipment-pricing-dataset
- Original portal ID: `a3rc-nmf6`
- Mirror repository: https://github.com/UmbertoFasci/Supply-Chain-Pricing-USAID
- Mirror Git blob SHA: `f65bdd023f4c816990690c50847ca2cb82d51c52`
- Local SHA-256: `c9ca9530539e7dbf37b377f3fcd383e1faa81c8e41c707e280b20a485508a537`
- Download date: 2026-10-06

The source covers historical deliveries from 2006 through 2015. It does not describe current USAID operations.

The transformation code, model specification, DAX measures, documentation and dashboard design in this repository are original portfolio materials. The source dataset remains attributed to USAID and its public mirror.
